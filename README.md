# K.F.C. Chat

용인시청소년수련관 로봇동아리의 웹 및 Windows 메신저입니다. 기존 홈페이지의 승인된 계정으로 로그인하며, 대화 기록은 K.F.C. Chat에 보관된 내용을 이어서 사용합니다.

## Windows 앱

- 기존 홈페이지와 같은 Electron 및 NSIS 방식으로 설치합니다. 설치 과정에서 폴더를 고를 수 있고 시작 메뉴와 바탕 화면에 바로가기가 생깁니다.
- 채팅 버전 업데이트와 홈페이지 앱 업데이트는 각자의 GitHub 릴리스에서 관리합니다.
- 기존 1.0 WinForms 설치판은 자동 업데이트가 없으므로 새 NSIS 설치 파일을 한 번 실행해야 합니다. 이전 앱을 제거하려면 새 앱 설치 전에 Windows의 설치된 앱 목록에서 제거하세요.
- 친구 목록, 1:1 대화, 그룹 채팅방 개설·초대·참여자 관리, 대화 검색, 이전 메시지, 답장, 복사, 수정, 모두에게서 삭제, 첨부, 반응, 읽음, 새 메시지 수, Windows 알림, 입력 중, 접속 상태, 대화 고정, 알림 끄기, 내 대화 지우기, 차단, 신고를 제공합니다. 신고로 접수된 내용은 관리자 계정에서 확인합니다.
- 첨부 파일 한 개의 크기는 4 MB 이하입니다. 메시지와 파일은 대화 당사자가 이용합니다. 동아리 관리자는 Windows 앱에서 대화 및 보관된 첨부 파일을 열람할 수 있으며, 열람 기록은 서버에 보관됩니다.

## 로그인 유지와 Windows 알림

- Windows 앱은 로그인을 현재 Windows 계정에 암호화해 저장합니다. 앱을 다시 열면 저장된 세션을 확인한 뒤 연결하며, 로그아웃을 누르면 저장된 세션을 지웁니다.
- 창을 닫으면 시스템 트레이에 남습니다. 새 메시지는 K.F.C. Chat 팝업에 표시되고, 팝업에서 바로 답장하거나 대화를 열 수 있습니다. Windows 잠금 중에는 메시지 미리보기를 표시하지 않습니다.
- 설치 마법사의 백그라운드 알림 페이지 또는 앱 설정에서 Windows 자동 시작을 선택할 수 있습니다. 선택하면 Windows 로그인 시 트레이에서 시작합니다. 트레이 메뉴의 앱 완전히 종료를 선택하면 다음 실행까지 알림 수신이 멈춥니다.
- 승인된 관리자는 Windows 앱의 대화 열람 메뉴에서 1:1 및 그룹 대화를 읽기 전용으로 확인할 수 있습니다. 관리자 계정, 열람한 대화, 열람 시각과 첨부 파일 확인 내역은 Supabase에서 기록합니다.

### 미니 채팅

Windows 앱의 설정이나 시스템 트레이에서 **미니 채팅 열기**를 선택하면 메인 창을 닫아도 작은 채팅창을 사용할 수 있습니다. 읽지 않은 대화를 열거나 받는 사람에서 친구와 채팅방을 골라 입력하고 보낼 수 있습니다. 미니 창의 닫기 버튼으로 이 기능을 끌 수 있습니다.

## 코드와 채팅방

- 메시지 입력란의 코드 모드를 열고 언어를 선택하면 들여쓰기와 줄바꿈을 유지한 코드 블록을 보낼 수 있습니다. 상대방은 코드를 한 번에 복사할 수 있습니다. 입력 중 Enter로 줄을 바꾸고 Ctrl+Enter로 보냅니다. 코드는 화면에 표시되며 앱이 실행하지 않습니다.
- 채팅방 목록에서 방을 만들고 승인된 동아리원을 초대할 수 있습니다. 방장은 참여자를 초대하거나 내보낼 수 있습니다. 초대한 동아리원은 초대 이후의 메시지부터 볼 수 있습니다.
- 채팅방을 나간 방장의 권한은 남은 승인 회원에게 넘어갑니다. 1:1 차단 관계에 있는 회원에게 새 초대를 보낼 수 없습니다.

## 마스코트 이모티콘

채팅 입력창의 마스코트 버튼에서 인사, 웃음, 응원, 엄지 척, 하트, 수리 동작을 골라 보낼 수 있습니다. 받은 이모티콘을 클릭하면 모션이 다시 재생됩니다. [스티커 원화](assets/kfc-sticker-sheet.webp)는 동아리 지구본 로고를 참조해 손그림 느낌의 2D 로봇을 그린 여섯 자세입니다.

## 빌드 및 배포

1. Windows x64 및 Node.js 24에서 `npm ci`, `npm test`, `npm run pack:win`을 실행합니다.
2. `outputs/windows/`에 NSIS EXE, blockmap, 최신 버전 매니페스트가 생성됩니다.
3. `codex/kfcchat` 브랜치의 GitHub Actions가 채팅 설치 EXE를 `chat-windows-latest` 릴리스에 게시합니다. 배포 버전을 바꿀 때 `package.json` 버전도 올려 주세요.
4. Vercel은 `web/` 진입점에서 Windows 앱과 같은 React 채팅 화면을 빌드합니다. 웹과 앱은 별도 로그인 세션으로 같은 K.F.C. Chat 기록을 사용합니다. Windows 설치 안내는 `/download`에 있습니다. 브라우저의 채팅 API 요청은 `https://kfcchat.vercel.app`에서만 허용합니다.
5. Supabase 변경 순서는 `supabase/kfc-chat-desktop.sql`, `supabase/kfc-chat-v2.sql`, `supabase/kfc-chat-v3.sql`, `supabase/kfc-chat-v4.sql`, `supabase/kfc-chat-v5.sql`, `supabase/functions/kfc-chat-desktop/index.ts`입니다. 마지막 함수가 서버에서 직접 토큰을 확인하므로 배포 시 `verify_jwt=false`를 사용합니다.
